Steps:
  1. Select IT Help Desk from the support services.
  2. Choose a date and time in Book a Slot.
  3. Write that you need help resetting your Gusto LMS password.
  4. Select Request Support.
Steps:
  1. Open Academic Hub.
  2. Go to Learning Materials or My Assignments.
  3. Select View Brief beside the assignment you need.
  4. The PDF brief will open or download for you to read.
Steps:
  1. Open Campus Life and go to Lost & Found.
  2. Select Report Item.
  3. Choose whether the item is Lost or Found.
  4. Enter the item name, category, date, location and description.
  5. Select Submit Report.

Reports you create are marked My Report, and only those reports can be deleted by you.

Steps:
  1. Open Academic Hub → My Assignments.
  2. Select Submit Assignment.
  3. Add one or more PDF, DOCX, PPTX or ZIP files.
  4. Remove any incorrect file before submitting if needed.
  5. Select Submit Assignment to save your submission.

If a result has already been graded as P, M or D, the submission becomes read-only.

Use General Enquiries for questions that do not belong to a specific module or service. You can also contact student support at 09-979387111.
